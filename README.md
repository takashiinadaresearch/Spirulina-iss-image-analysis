# Spirulina Surface Area Analysis Macro for Fiji

This directory contains the ImageJ/Fiji macro (`.ijm`) used for automated segmentation and surface area measurement of *Spirulina* on porous substrates.

## 📄 Contents
- `macros/spirulina_area_analysis.ijm`: Image processing pipeline (SIFT alignment, G-channel extraction, Moments thresholding, and ROI measurement).

## 🚀 How to Use
1. Download and install [Fiji (ImageJ)](https://fiji.sc/).
2. Open Fiji and drag & drop the `spirulina_area_analysis.ijm` file into the main window.
3. Click **Run** in the script editor.
4. Select the target folder containing your image sequence.
